# Architecture decision records

Significant design decisions are recorded as short ADRs, following
[Michael Nygard's format](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions):
context, decision, consequences. An ADR is never edited after it is
accepted; a later ADR supersedes it instead.
